# Modal API

Modal 的 API 与 `@kne/react-modal` 保持一致。

请前往 **@kne/react-modal** 文档查看完整属性说明，包括 `Modal`、`useModal`、`useConfirmModal`、`createModalRender`、`TabsLayout`、`ColumnsLayout`、`ScrollRegion`、`modalClassNames` 等。

## 本仓补充

- 表单弹窗：使用 `@components/FormInfo` 的 `FormModal` / `FormDrawer` / `FormStepModal`（内部通过 `createModalRender` 对接 Modal）
